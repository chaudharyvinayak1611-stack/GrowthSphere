# GrowthSphere Digital

A responsive, multi-page static website for a digital marketing agency demonstration project.

## Pages
- Home: `index.html`
- About: `about.html`
- Services: `services.html`
- Blog: `blog.html`
- Contact: `contact.html`

## Publish with GitHub Pages
1. Create a public GitHub repository named `GrowthSphere-Digital`.
2. Upload the contents of this folder to the repository root (not the containing folder).
3. Open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Replace `YOUR-USERNAME` in canonical URLs, structured data, `robots.txt` and `sitemap.xml` with your GitHub username.
6. Wait for GitHub Pages to publish the site.
